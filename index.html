Бид ямар асуудал олж харсан бэ?

Орчин үеийн хүүхдүүд гар утас, компьютер их үзэж, гадаа тоглох нь багассанаас хөдөлгөөний дутагдалд орох асуудал нэмэгдэж байна. Тиймээс бид тоглоомыг хөдөлгөөнтэй хослуулах санааг сонгосон.

Хөдөлгөөн багасах

Дэлгэцийн хэрэглээ ихсэхээр идэвхтэй хөдөлгөөн хийх цаг багасдаг.

Шийдлийн санаа

Тоглоомын сонирхлыг ашиглан хүүхдүүдийг босож, хэмнэлтэй хөдөлгөх.

DDR-ээс санаа авсан

2000-аад онд алдартай байсан Dance Dance Revolution тоглоомын зарчмыг өөрсдийн хувилбараар бүтээсэн.

Төслийн тухай

Төсөл нь хоёр үндсэн хэсгээс бүрдэнэ: бодитоор гишгэх тавцан болон Godot дээр хийсэн тоглоом.

Зорилго

Arduino ашиглан бүжгийн хавтан хийж, электроник, программчлал, багийн хамтын ажиллагааны мэдлэгээ бататгах.

Бүрэлдэхүүн

Мод, тугалган цаас, поликарбонат, утас, Arduino Leonardo болон Godot тоглоомын хэсгээс бүрдэнэ.

Үр дүн

Багаар ажиллах, Arduino холбох, кодны алгоритм, техник хангамжийн угсралтын талаар илүү ихийг сурсан.

Яаж ашиглах вэ?

Тавцанг компьютертой холбосны дараа дэлгэц дээр гарч буй сумнуудын хөдөлгөөн, хөгжмийн хэмнэлд тааруулан харгалзах хэсэг дээр гишгэнэ.

Тавцан дээр гишгэнэ

Хөлөөр даралт өгөхөд дээд болон доод тугалган цаас хоорондоо хүрч, цахилгаан хэлхээ холбогдоно.

Arduino дохио уншина

Digital pin тухайн даралтыг мэдэрч, дарагдсан эсэхийг LOW/HIGH төлөвөөр ялгана.

Keyboard input илгээнэ

Arduino Leonardo USB-ээр W, A, S, D товч дарагдсан мэт компьютер лүү дохио илгээдэг.

Тоглоом оноо өгнө

Godot тоглоом сум болон хөгжмийн хэмнэлтэй таарсан гишгэлтийг шалгаж оноо өгнө.

Тавцангийн бүтэц

Танилцуулгад дурдсан үндсэн давхаргуудыг сайт дээр илүү ойлгомжтойгоор харууллаа.

1. Поликарбонат: дээд хамгаалалтын хэсэг
2. Тугалган цаас: дарахад хүрэлцдэг мэдрэгчийн нэг тал
3. Тугалган цаас: хэлхээ холбох доод тал
4. Мод: тавцангийн суурь, бат бөх хэсэг

Технологи

Төслийг хийхдээ Arduino Leonardo болон Godot game engine ашигласан.

Arduino Leonardo

ATmega32U4 дээр суурилсан микроконтроллерийн самбар бөгөөд USB холболтоор гар, хулганыг дуурайх боломжтой.

Godot Engine

2D болон 3D тоглоом бүтээхэд зориулагдсан, GDScript, C#, C++ ашигладаг, нээлттэй эх сурвалж бүхий үнэ төлбөргүй тоглоомын систем.

Кодны санаа

Код нь 4 товчийг уншиж, дарагдсан үед Keyboard.write() ашиглан W, A, S, D дохионы аль нэгийг илгээнэ. Prev төлөв ашигласнаар товчийг удаан дарсан ч давхар дохио илгээхгүй.

if (buttonState == LOW && previousState == HIGH) {
    Keyboard.write('W');
}
previousState = buttonState;

Arduino Uno-ийн оронд Arduino Leonardo ашиглаж, Godot дээрх алдаануудыг туршиж зассаар төслөө ажиллуулж чадсан.
